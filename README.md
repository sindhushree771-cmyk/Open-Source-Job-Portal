# Open Source Job Portal

## Project Overview
Open Source Job Portal is a simple web-based application developed to help users search and explore job opportunities. It provides an easy-to-use interface for viewing job listings and submitting applications.

## Features
- View available job listings.
- Search jobs using keywords.
- Filter jobs by location and job type.
- Post new job vacancies.
- Apply for available jobs.
- View submitted applications.
- Simple and user-friendly interface.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- `index.html` – Website structure.
- `style.css` – Website styling.
- `script.js` – Interactive functionalities.

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Explore the job portal features.

## Conclusion
This project demonstrates the basic functionalities of a job portal using frontend web technologies. It helped in understanding website development, JavaScript interactions, and responsive design.
